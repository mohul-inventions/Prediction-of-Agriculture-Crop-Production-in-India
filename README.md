# Prediction of Agriculture Crop Production in India

## Project Overview

This project uses Machine Learning to predict agriculture crop production in India based on factors such as state, crop, year, cultivated area, rainfall, fertilizer usage, and pesticide usage.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Models

- Linear Regression
- Random Forest Regressor

## Project Workflow

1. Dataset collection
2. Data loading
3. Data preprocessing
4. Feature selection
5. Data visualization
6. Model training
7. Model evaluation
8. Crop production prediction
9. Model comparison

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
